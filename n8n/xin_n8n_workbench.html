n8n 工作流程自動化

用 n8n 改善 5 項重複性營運作業

週報、對帳、庫存與營收檢核，都是重複又容易出錯的工作。我針對每個情境整理出判斷規則，用 n8n 建成流程：計算與判斷交給固定規則，需要寄出的內容先產生草稿，由人確認後再寄。每張卡片都附一個例子，也可以點進去實際操作。

流程中使用的 n8n 功能

← 可左右拖曳 →
Webhook接收網頁送來的資料
Code 節點檢查資料、計算比率
IF／Switch依條件分成多條路徑
Edit Fields設定判斷結果欄位
Gmail自動建立 Email 草稿
Respond to Webhook把結果回傳給網頁
Google Sheets週報原版：新增資料列即觸發
1　資料進來

在網頁輸入一筆，或一次送出整批資料

2　依規則判斷

n8n 依工作類型分流，套用各自的規則

3　自動產出

回傳判斷結果；週報與補貨會建立 Email 草稿，寄出前由人確認

4　留下紀錄

每次執行的結果與耗時都記錄下來，可以匯出

執行紀錄

每一筆都記下來源（n8n 或示範模式）、結果與耗時。共 0 筆，測試資料與預期相符 —。紀錄只存在這台電腦的瀏覽器，換電腦前請先匯出。

時間流程資料 ID來源結果預期相符耗時

連線設定

貼上 n8n 工作台 API 的 Webhook 網址後，網頁就會把資料送到 n8n。沒填網址時，用網頁內建的同一套規則做示範，不會建立草稿。

網址只存在這台電腦的瀏覽器裡。

第一次設定

  1. 在 n8n 匯入 xin_n8n_portal_api.json
  2. 打開三個 Gmail 節點，確認選到你的 Gmail 憑證
  3. 按 Publish（或把流程切成 Active）
  4. 點「接收網頁請求」節點，複製 Production URL 貼到上方欄位
  5. 按「測試連線」，看到「連線正常」
  6. 按「寄一封測試信」，到信箱確認收到

Gmail 寄送測試

由 n8n 透過 Gmail 寄一封測試信到預設信箱，確認寄信設定正常。

連線 n8n 後即可使用。
